# QA Engineer Portfolio - Kizar Akib Ayon

A responsive, modern portfolio website for QA Engineer Kizar Akib Ayon, showcasing skills, experience, and projects.

## Features

- Responsive design for all devices
- Day/Night mode with theme persistence
- Interactive particle.js background
- Project filtering by category
- Contact form with email functionality
- Smooth scrolling and animations
- Skills visualization with progress bars

## Tech Stack

- HTML5
- CSS3
- JavaScript
- jQuery
- Particles.js
- Font Awesome
- Google Fonts

## Setup Instructions

1. Clone or download this repository
2. Open `index.html` in your browser

For the email functionality to work properly in a production environment, you'll need to:

1. Sign up for a service like [EmailJS](https://www.emailjs.com/)
2. Replace the placeholder code in `email.js` with your actual EmailJS configuration

## Customization

To personalize this portfolio:

1. Replace the profile image in `images/profile.jpg`
2. Update project images in `images/projects/`
3. Edit content in `index.html`
4. Modify contact information
5. Update social media links
